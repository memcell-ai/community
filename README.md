# MemCell Community Hub & Public Roadmap

Welcome to the **MemCell Community** repository!

This repository acts as the public issue tracker, feature request forum, and roadmap database for the [MemCell Platform](https://memcell.ai).

## 🗺️ Public Roadmap

You can track our live, synchronized roadmap directly in the MemCell Web Console:
👉 **[memcell.ai/feedback](https://memcell.ai/feedback)**

## 💡 Submitting Feedback & Feature Requests

You can submit feedback in two ways:
1. Directly within the MemCell web console by clicking **Feedback** in the navigation header or account menu.
2. By opening an issue directly in this repository using our issue templates.

## 🏷️ Status Labels
- `status:under-review`: New submissions being reviewed by the maintainers.
- `status:planned`: Approved initiatives scheduled for development.
- `status:in-progress`: Currently being designed, built, and tested.
- `status:completed`: Shipped and available in released versions.
